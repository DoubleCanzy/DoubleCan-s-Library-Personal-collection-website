## 当前执行原则

1. **一次只做一件事**：每个阶段完成并验证后再进入下一阶段
2. **先骨架后血肉**：先确保页面结构和路由通顺，再填充交互细节
3. **随时可验证**：每个阶段都应有可视化的产出（页面能看到、功能能用）
4. **文档同步更新**：每天结束时更新 dev-logs，阶段性更新 docs
