# 项目需求文档

## 项目名称
**DoubleCan's Library** — 个人作品收藏网站

## 项目目标
搭建一个可部署上网的个人图书馆网站，用于收藏、展示、管理自己喜欢的小说、动画、漫画作品。

## 用户故事

### 首页体验
- 用户打开网站，看到以画廊形式展示的所有已上传作品封面
- 页面底部有一个 "Link Start" 按钮
- 点击按钮进入动态页

### 作品管理
- 用户可以添加新作品，填写封面、标题、作者、简介、出版时间、出版社、卷数等信息
- 所有字段都是可选的，可以留空
- 可以随时编辑已上传的作品信息
- 可以删除作品

### 动态浏览
- 以时间线形式展示最近添加的作品和书评
- 侧栏显示用户个人信息（头像、昵称、简介、所在地、邮箱）
- 侧栏有日历组件，点击不同日期可以筛选该日期的动态
- 右下角浮动按钮切换到图书馆页面

### 图书馆浏览
- 以宫格形式展示所有作品封面
- 侧栏提供标签筛选功能
- 输入标签时有自动提示（显示已有标签）
- 可以多选标签进行筛选

### 书评功能
- 在作品详情页可以查看、添加书评
- 书评按时间倒序排列
- 可以删除书评

### 标签功能
- 添加/编辑作品时可以输入标签
- 输入标签时自动提示已有标签
- 标签可用于图书馆页面的分类筛选

## 功能优先级
1. **P0 核心**：作品 CRUD、画廊展示、图书馆宫格展示
2. **P1 重要**：标签系统、书评系统、动态时间线
3. **P2 增强**：日历日期筛选、个人信息卡片、标签自动提示
4. **P3 打磨**：加载动画、空状态提示、移动端适配
